# Profile Retouch Studio v2.9

v2.9는 **영상 저장 시간과 움직임 속도가 느려지던 문제를 수정한 버전**입니다.

## 중요한 수정
이전 버전에서 5초 프로젝트가 약 10초 영상으로 저장되거나, 장식/회전/페이드가 약 2배 느려지는 현상이 있을 수 있었습니다.

v2.9에서는 영상 시간을 실제 녹화 경과시간과 동기화합니다.

따라서:
- 5초 프로젝트 → 약 5초 영상
- 미리보기와 저장 영상의 움직임 속도 일치
- 고해상도 렌더링이 잠시 느려져도 전체 영상 시간을 늘이지 않음

## 기존 기능
- 최대 2000×2000 1:1 영상
- 최대 60FPS
- 30 / 50 / 80Mbps 저장
- 여러 사진 레이어
- 귀여운 장식 24종
- PNG 장식
- 원형 프레임 PNG
- Undo / Ctrl+Z
- 간단 타임라인

## 배포
`index.html` 기반 정적 프로젝트이므로 Cloudflare Pages / GitHub Pages에 그대로 배포할 수 있습니다.
