# Profile Retouch Studio v2.4

브라우저에서 바로 열 수 있는 **단일 HTML 기반 프로필 모션 제작 도구**입니다.

## 주요 기능
- 배경 위에 사진 여러 장 올리기
- 레이어 순서 변경
- 레이어별 등장/퇴장 효과 설정
- 1:1 비율 유지
- 2000×2000px까지 출력
- MP4 우선 저장 (브라우저 미지원 시 WebM 대체)
- 투명 배경 원형 프레임 PNG 업로드 및 회전 애니메이션

## 사용 방법
1. `index.html`을 브라우저에서 엽니다.
2. 왼쪽에서 배경을 선택합니다.
3. `+ 사진 불러오기`로 여러 장의 이미지를 추가합니다.
4. 레이어를 선택해 위치, 크기, 등장 효과, 시간 등을 수정합니다.
5. 오른쪽에서 원형 프레임 PNG를 올리고 회전 옵션을 조절합니다.
6. `MP4 저장` 버튼으로 영상 파일을 저장합니다.

## 배포
정적 파일만 있으므로 GitHub Pages / Cloudflare Pages에 그대로 업로드 가능합니다.
