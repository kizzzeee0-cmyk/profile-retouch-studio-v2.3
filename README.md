# Profile Retouch Studio v2.6

브라우저에서 바로 열 수 있는 **단일 HTML 기반 프로필 모션 제작 도구**입니다.

## 주요 기능
- 사진 여러 장을 배경 위에 겹치기
- 귀여운 장식 24종 레이어
- 업로드한 PNG를 장식처럼 여러 개 뿌리기
- 원형 프레임 PNG 업로드 및 회전
- 간단 타임라인으로 레이어 시간 확인
- 등장 효과 / 장식 움직임 미리보기
- 재생하지 않아도 선택한 레이어를 볼 수 있는 편집 미리보기
- MP4 우선 저장 (미지원 브라우저는 WebM 대체)

## 사용 방법
1. `index.html`을 브라우저에서 엽니다.
2. 배경을 설정합니다.
3. `+ 사진`, `+ 귀여운 장식`, `+ PNG 장식` 버튼으로 레이어를 추가합니다.
4. 왼쪽 레이어 목록 또는 타임라인에서 레이어를 선택합니다.
5. 오른쪽에서 위치, 크기, 시작/끝 시간, 등장/퇴장 효과, 방향 등을 수정합니다.
6. 가운데 미리보기로 확인하고 `MP4 저장`을 눌러 내보냅니다.

## 포인트
- `편집 미리보기 ON` 상태에서는 현재 시간이 아니어도 선택한 레이어를 흐리게 볼 수 있어 위치 잡기가 쉽습니다.
- 장식 방향은 나침반 버튼으로 선택할 수 있습니다.
- 등장 효과와 장식 움직임은 작은 미리보기 캔버스로 확인할 수 있습니다.

## 배포
정적 파일만 사용하므로 GitHub Pages / Cloudflare Pages에 그대로 업로드해 사용할 수 있습니다.
