# Profile Retouch Studio v2.8

브라우저에서 바로 열 수 있는 **단일 HTML 기반 프로필 모션 제작 도구**입니다.

## 이번 버전 핵심
- **60FPS 출력 지원**
- **Undo 버튼 추가**
- `Ctrl + Z` / `Cmd + Z` 지원

## 주요 기능
- 사진 여러 장을 배경 위에 겹치기
- 귀여운 장식 24종 레이어
- 업로드한 PNG를 장식처럼 여러 개 뿌리기
- 원형 프레임 PNG 업로드 및 회전
- 간단 타임라인으로 레이어 시간 확인
- 등장 효과 / 장식 움직임 미리보기
- 재생하지 않아도 선택한 레이어를 볼 수 있는 편집 미리보기
- MP4 우선 저장 (미지원 브라우저는 WebM 대체)

## 사용 방법
1. `index.html`을 브라우저에서 엽니다.
2. 배경을 설정합니다.
3. `+ 사진`, `+ 귀여운 장식`, `+ PNG 장식` 버튼으로 레이어를 추가합니다.
4. 왼쪽 레이어 목록 또는 타임라인에서 레이어를 선택합니다.
5. 오른쪽 편집 패널에서 위치, 크기, 시간, 효과 등을 수정합니다.
6. 잘못 수정했으면 상단의 `↶ Undo` 버튼 또는 `Ctrl+Z`를 누릅니다.
7. 출력 FPS를 60으로 두고 `고화질 MP4 저장`으로 내보냅니다.

## 배포
정적 파일만 사용하므로 GitHub Pages / Cloudflare Pages에 그대로 업로드해 사용할 수 있습니다.
