# Profile Retouch Studio v2.7

v2.7은 **미리보기와 저장 결과의 차이를 줄이는 것**에 초점을 둔 업데이트입니다.

## 주요 기능
- 상단 고정 재생/정지/저장 툴바
- 최대 2000×2000 1:1 영상 제작
- 미리보기와 동일 해상도 기반 Master Canvas 렌더링
- 30 / 50 / 80 Mbps 고화질 영상 저장
- 여러 사진 레이어
- 귀여운 장식 24종
- PNG 장식 업로드
- 원형 프레임 PNG
- 타임라인 및 효과 미리보기

## 추천 저장 설정
가장 미리보기와 비슷한 결과를 원하면:
- 출력 크기: 2000×2000
- FPS: 12~24
- 영상 화질: `미리보기 우선 · 50Mbps` 또는 `초고화질 · 80Mbps`

## 배포
`index.html` 중심의 정적 프로젝트이므로 Cloudflare Pages / GitHub Pages에서 별도 빌드 없이 사용 가능합니다.
