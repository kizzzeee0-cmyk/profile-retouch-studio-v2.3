# Profile Retouch Studio v2.5 Final Spec

## 버전명
**v2.5 — Text-like Photo FX & Cute Decorations Update**

## 핵심 기능
### Photo Layers
- multiple image layers
- order control
- richer in/out effects
- text-like reveal effects for text-designed image assets

### Built-in Cute Decorations
- 24 built-in decoration types
- adjustable count, size, spread, speed, direction, colors
- motion modes: drift / float / fall / burst

### Uploaded PNG Decoration Layer
- user PNG asset replication
- count / size / speed / direction / spread control
- tint color and tint strength
- rotate mode and rotate speed

### Common Layer Controls
- start / end timing
- in / out effect
- in / out duration
- x / y / scale / rotation / opacity

### Export
- square MP4-first export
- 1000 / 1500 / 2000 output sizes
- WebM fallback when MP4 recording unsupported
