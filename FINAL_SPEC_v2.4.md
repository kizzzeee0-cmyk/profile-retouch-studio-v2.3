# Profile Retouch Studio v2.4 Final Spec

## 버전명
**v2.4 — Multi Photo Motion & MP4 Update**

## 핵심 기능
### 1) Multi Photo Layers
- multiple image layers on top of background
- per-layer order control
- per-layer timing and in/out effects

### 2) MP4-first Export
- square export only
- 1000 / 1500 / 2000 output sizes
- MP4 preferred, WebM fallback when browser lacks MP4 recording support

### 3) Custom Circular Frame PNG
- transparent PNG frame upload
- scale control
- opacity control
- rotation on/off
- rotation speed and direction

### 4) Background System
- color / gradient / image background
- pastel gradient presets
- hue adjustment
- background image position and scale
