# Profile Retouch Studio v2.8 Final Spec

## 버전명
**v2.8 — 60FPS Export & Undo Update**

## 핵심 기능
### 1) 60FPS Export
- export FPS options: 10 / 12 / 15 / 24 / 30 / 60
- default FPS: 60
- smoother animation and transitions

### 2) Undo System
- toolbar Undo button
- Ctrl+Z / Cmd+Z shortcut
- undo support for:
  - layer transform changes
  - timing changes
  - effect changes
  - decor and sprite option changes
  - frame/background changes
  - layer add / delete / duplicate / reorder
  - output setting changes

### 3) Top Toolbar
- play
- pause
- edit preview toggle
- undo
- export
- output info badge

### 4) Export
- square MP4-first export
- WebM fallback when MP4 unsupported
- up to 2000×2000 output
- high bitrate export options maintained
